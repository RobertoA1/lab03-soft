# Copilot Instructions

## Project Context

- Product: Sistema de Información de Agricultura de Precisión
- Primary user: Agronomist
- v1 focus: manual/seed data, interactive dashboard, historical charts, and actionable alerts
- v1 out of scope: PDF reports, external integrations, IoT ingestion, and full n8n automation

## Current Workflow

1. Read `.planning/PROJECT.md` before making project-level decisions.
2. Use `.planning/REQUIREMENTS.md` and `.planning/ROADMAP.md` as the source of truth for scope.
3. Keep changes aligned with the current phase in `.planning/STATE.md`.
4. Preserve the agronomist-first, operationally focused scope.
